## F01—F24 实现追踪

| 功能 | 实现 | 验证／限制 |
|---|---|---|
| F01 通用引用 | source + MetadataCache + rules + rendered + Provider | 直接、动态、候选、无法关联分级；未知语法不猜原件 |
| F02 原件身份 | MetadataCache 相对源笔记解析、Vault resource URL 索引 | 同名、改名和非原件 URL 自动测试；真实宿主仍需验证 |
| F03 格式探测 | JPEG、XMP namespace、MP4、MPF、EXIF、可信 Apple 配对 | 缺少可信结构返回保护原因；识别不是全部可压缩 |
| F04 照片式播放 | 原 img + 非交互 video layer | 永无控件；真实帧和宿主样式需分别测试 |
| F05 LIVE 客制化 | 主题变量、位置、文字／圆环、尺寸、透明度 | 主题及重复挂载资源测试；真实主题组合待验证 |
| F06 自动静音 | 首次可见、进入、循环、悬停、冷却、并发 | 所有自动入口代码强制静音；低资源依 WebView 能力降级 |
| F07 手动声音 | 点击、循环、继续／重播、音量及拒绝降级 | 系统声音和自动播放许可不绕过；手机限制待验证 |
| F08 手势仲裁 | 捕获阶段、拖拽、修饰键、长按、多指、查看器策略 | 不接管普通图片和 caption；真实查看器组合待验证 |
| F09 扫描范围 | 当前文章、搜索选定文件、全库、共享清单 | 未保存正文拒绝；动态及候选需确认 |
| F10 普通压缩 | JPEG、8-bit PNG RGBA、静态 WebP | 保护 ICC/特殊元数据、动画及未验证路线 |
| F11 视频单独 | 保持静态资源字节，重写实况长度 | 完整解码、帧时间、方向、色彩、音轨样本和封面校验 |
| F12 照片／双重 | SDR 重新编码 + XMP；HDR 双意图 + MPF | 附加元数据无可信写入能力则保护，不能一律保证厂商文件 |
| F13 Apple 配对 | MakerApple ID + QuickTime ID + mebx key/sample；视频 graft | 实验视频路线默认关闭；HEIC／照片重编码及相册识别未通过门槛 |
| F14 HDR 保护 | gain-map 完整解码、重建、MPF 和辅助元数据保护 | 不静默 SDR；有损重建需要用户允许；真实 HDR 显示待验证 |
| F15 分步对比 | 选择 → 临时编码 → 照片对比 → 最终保存 | 模态实际 Obsidian 布局待用户确认 |
| F16 串行取消 | busy guard、AbortSignal、Worker／进程停止、组提交 | 未开始队列停止；配对组避免主动半提交 |
| F17 备份恢复 | DataAdapter、指纹、读回、日志、条件恢复、导出副本 | 不覆盖用户修改；跨设备最后写入窗口受 DataAdapter 限制 |
| F18 重复保护 | 输入、配置及输出指纹；已有副本不重复编码 | 只识别本插件日志，不推测第三方压缩历史 |
| F19 偏好 | 113 字段 schema、平台、笔记、照片、预设、导入差异 | 安全项不能覆盖；编码前冻结；设备执行许可不随设置同步 |
| F20 性能资源 | Worker 懒加载、预算、缓存、离屏回收、销毁 | 预算不是进程内存上限；大库及手机实测待验证 |
| F21 诊断 | 检查命令、能力原因、代码化日志、脱敏路径 | 不导出私人正文／媒体字节；隐藏事务记录属于私人数据 |
| F22 无障碍主题 | Enter／Space／Escape、主题变量、减少动态、窄屏 | CI 验证限定环境；真实键盘和屏幕阅读器待验证 |
| F23 跨平台共存 | 移动预算、按需桌面 Node、公开宿主入口 | 不承诺任意插件视图或未知私有语法都可处理 |
| F24 Actions 产物 | 固定依赖、构建一次、单独下载测试、hash、来源与源码包 | 实机门槛未过，正式发行被守卫阻止 |

## 设置结论

schema 包含正好 113 项，默认、校验和设置界面同源；字段用途见[设置参考](设置参考.md)。这不等于 113 项均已由真实 Obsidian 逐项验收。

`compression.targetVideoMbps` 因 WebCodecs 保护门槛未过，在界面禁用并说明；选择 WebCodecs 会明确拒绝，不伪造成功。`auto` 当前使用经过验证的 WASM。Apple 压缩默认关闭。部分格式、缩放、元数据清除受保护条件限制，这些拒绝行为必须真实可见。
