# Live Media 0.1.5 播放修复

## 问题与改动

- 放大图片过去没有经过 Markdown 后处理或编辑器扩展，图片仍是静态。新增查看器观察器，只接入能通过公共 Vault 资源地址精确找到原件的图片；不读取其他插件私有实现，不按同名推测身份。右键仍交给原有宿主处理，在其放大图片上添加同一套 LIVE 播放层。
- 实时预览扩展原来只在构造和来源改变时尝试挂载；首次文件信息尚未就绪、晚到图片及没有新事务时会漏挂。现在在事务外挂载，监听异步 DOM、重试晚到来源，并响应公共工作区事件。源码视图不接管。阅读后处理与编辑器扩展通过图片所有权防止重复创建播放器。
- 可见播放过去遇到并发上限直接放弃，未播放过的照片执行 stop 也会触发冷却；高图可能永远达不到整张 60% 可见。现在等待前一张释放播放额度，冷却只针对实际播放，按照当前视口能容纳的照片面积计算可见比例。
- 所有自动播放入口继续强制 muted；左键手动播放可以有声音，再次左键停止。没有播放器按钮、进度条、时间和音量条。放大层随布局调整，关闭查看器释放视频、监听器和资源。

压缩、备份、读回、文件身份保护及默认输出策略未修改。未知远程、缩略图或无法验证原件的 Blob 不凭空绑定。主窗口 DOM 查看器可通用接入；Canvas、独立弹出窗口、Canvas 绘制型第三方查看器或另行生成的 Blob/缩略图仍需要运行时核验，不能宣称任意查看器均兼容。

## 官方依据

- [Obsidian 编辑器扩展](https://docs.obsidian.md/Plugins/Editor/Editor%20extensions)：实时预览应使用 CodeMirror 扩展。
- [Obsidian Markdown 后处理](https://docs.obsidian.md/Plugins/Editor/Markdown%20post%20processing)：阅读视图使用后处理，不能代替编辑器接入。
- [IntersectionObserver thresholds](https://developer.mozilla.org/en-US/docs/Web/API/IntersectionObserver/thresholds)：可见阈值是观察器的触发边界，需要覆盖可配置条件。
