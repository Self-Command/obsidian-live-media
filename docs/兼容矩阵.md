# Live Media 0.1.1 兼容矩阵

“识别”是结构检查；“播放”依赖当前 WebView；“可压缩”还要求编码、完整解码及保护校验通过。所有写入仍需用户最终确认。

## 格式

| 格式 | 识别／播放 | 压缩 | 限制 |
|---|---|---|---|
| 普通 JPEG | 图片保留宿主显示 | 有损重编码、受限缩放 | 不假称 JPEG 无损优化；sRGB/P3 RGB matrix ICC 原样保留并比较浏览器解码色彩；未知 ICC、ICC 缩放、CMYK、Apple MakerNote、多图及未知布局保护 |
| PNG | 图片保留宿主显示 | 8-bit 无损，逐像素 RGBA 比较 | 保护 APNG、ICC/HDR、未验证辅助块；保留支持的文本、时间和物理尺寸块 |
| 静态 WebP | 图片保留宿主显示 | 无损优先；显式允许有损路线 | 动画、EXIF、ICC、XMP 和未验证缩放保护 |
| JPEG Motion Photo | XMP namespace + 实际 MP4 容器 | video-only / photo-only / photo-and-video | 视频帧时刻、方向、色彩和音轨必须一致；照片路线仅处理已登记元数据 |
| 旧 MicroVideo | 已登记偏移与可信容器 | 同上，视频单独路线优先 | 冲突偏移、无写入空间或布局不明时跳过 |
| Ultra HDR 实况／静态图 | MPF + gain-map 完整解码 | libultrahdr 双意图重建 | 同色域和尺寸、线性光相对 RMS ≤10%；不支持 HDR 缩放及隐私元数据清除；无法保留辅助数据则保护 |
| Apple JPEG + MOV | MakerApple key 17、QuickTime ID、真实 mebx 键与样本 | 实验 video-only 媒体组 | 默认关闭；照片字节不变；复杂编辑列表、未验证样本映射和真实相册识别待确认 |
| 用户明确配对 | 允许尝试照片式播放 | 不能凭设置伪造可信 Apple 配对 | 播放支持不意味着允许压缩 |
| HEIC/HEIF、AVIF、GIF/APNG、TIFF 等 | 魔数与受限能力说明，显示沿用宿主 | 保护跳过 | 不静默转 JPEG、SDR 或单帧 |

VFR 若不能保持精确帧时刻，拒绝结果。更大文件或不足最低节省比例的结果不会提交。

HDR 重建可能生成不同的 ICC 和增益图，这是经过允许的有损重编码，不是 ICC 字节保留。插件对两个文件的 HDR 解码结果比较色域、尺寸和线性光误差，失败即跳过；EXIF 和原始 JPEG 注释另行保留。10% 是该候选的保护上限，不是所有设备显示效果的保证。

## 插件语法与宿主

| 来源 | 接入方式 | 状态 |
|---|---|---|
| Obsidian 原生 Wiki/Markdown 嵌入 | 源码 + MetadataCache + Vault 解析 | 自动测试已有覆盖；实际 Obsidian 待验证 |
| Simple Gallery | 声明式 list 规则 + 实际 img 资源身份 | 支持 `- ![[...]]`、`- [[...]]` 和裸路径；真实点击／拖拽待验证 |
| HTML img / source srcset | 直接源码引用；资源 URL 校验 | 自动解析覆盖；响应式宿主运行时待验证 |
| 异步图库／动态查询 | 渲染后普通 img + Vault 原件 URL | 标记动态展示，默认不勾选压缩；远程缩略图不按文件名猜原件 |
| 未知代码块 | 标准嵌入仅为候选 | 明确选择后才处理；可增加声明式规则 |
| 特殊私有语法 | ReferenceProvider v1 | 插件主动提交真实来源；不读取私有实现，错误和超时隔离 |
| 大图查看器 | LIVE 优先或查看器优先 + 替代手势 | 修饰键可交回宿主；替代手势需显式配置；真实插件组合待验证 |
| 历史 live 语法 | 默认关闭的检测选项 | 不替换其他插件的 code block renderer，不承诺冲突插件同时接管 |

## 平台与后端

| 平台／后端 | 当前证据 | 边界 |
|---|---|---|
| CI Chromium | 离线 Worker/WASM、合成文件完整解码、照片交互自动测试 | 不是 Obsidian 实机验收 |
| Obsidian 桌面 | 使用公开插件入口；下载 main.js 的 API stub 冒烟测试 | 编辑器、主题、弹出窗口及其他插件组合待用户实测 |
| Android / iOS | 平台预算、Node 仅按需桌面导入、强制静音路径已实现 | WebView CSP、编解码、系统音量、内存与相册识别待用户实测 |
| 内置 WASM | FFmpeg、UltraHDR 固定源码构建，单线程、无 CDN | 首次压缩才加载；资源超限或不支持时跳过 |
| WebCodecs | 当前不可选用为有效压缩路线 | 未过音轨与时间保护门槛；固定码率设置禁用并说明 |
| Native FFmpeg | CI 测试显式授权与 JPEG 编码解码 | 仅桌面、本机授权，不从同步偏好继承执行许可 |

manifest 的 `minAppVersion=1.8.7` 是候选 API 下限，不是已实机通过的版本声明。较旧 WebView 缺少 DecompressionStream、Worker/CSP 或相应解码器时报告不可用；真实最低版本需要按实机结果调整。

## 对应规范

Apple 的 keyed timed metadata 要匹配样本描述中的 key 与实际样本，不能只搜索文件内出现的字符串。独立实现依据 [timed metadata sample descriptions](https://developer.apple.com/documentation/quicktime-file-format/timed_metadata_sample_descriptions)、[key declaration](https://developer.apple.com/documentation/quicktime-file-format/metadata_key_declaration_atom) 和 [sample format](https://developer.apple.com/documentation/quicktime-file-format/timed_metadata_sample_data_format)。此结构测试不能证明手机相册认可合成配对。

0.1.1 的新增回归和边界见[修复复检记录](0.1.1-修复复检.md)。原位点击播放与宿主放大图内的播放是不同宿主，本轮修复前者的按下事件竞争。
