# Live Media 实施追踪

用户批准的设计契约为开发报告 v2：F01—F24、113 项设置、T01—T13。

1. 工程与离线编码器门槛：公开源码、Actions 依赖锁、三文件安装、离线 Worker/WASM、取消与释放。
2. 检测与照片播放：真实身份、来源分级、图库共存、静音自动预览、手动声音及资源管理。
3. 压缩与恢复：格式保护、预检和对比、串行提交、指纹、备份与条件恢复。
4. 综合验收：Actions 原始产物下载和核验、独立测试库、手册与逐功能报告。

当前：工程、独立实现、113 项设置、离线编解码、检测播放和批次恢复已形成候选。编码器保护校验和 Actions 验收持续修复；最终提交／run／SHA256 以[复检报告](复检报告.md)为准，不将旧成功运行充当新版结果。
