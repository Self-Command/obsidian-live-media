# Live Media 0.1.6：放大对齐与所有可见 LIVE 同时预览

## 故障与修复

用户截图中的大图上浮着缩略图尺寸的播放层。安装版本 0.1.5 的浏览器测试只验了静态容器里能解码播放，没有覆盖原生 lightbox 打开期间的图片 transform。只读检查本机 Obsidian 资源的 DOM 和布局逻辑，确认原生查看器在图片本身应用从缩略图位置到全屏的 transform，缩放和平移也作用于图片；ResizeObserver 不通知纯 transform 改变。此检查没有启动插件或操控界面，没有复制应用实现。

新增独立 PhotoGeometry：在图片同一定位坐标系中保留未变换尺寸、内边距与边框，镜像图片的 transform、transform-origin、opacity、object-fit 和 object-position；监听图片及祖先 style/class、窗口尺寸和动画帧，跟随开合动画、缩放和平移。重挂载时释放旧层。查看器原有 pointer 流保留，移动手势不误当播放点击。

并发设置增加 `all-visible`，表示所有实际可见实况同时静音预览；范围是屏幕可见内容，不一次播放全库。数值 1—3 仍可选择。预算策略增加 `keep-configured`，明确保留用户所选并发。默认全局值仍兼容旧用户；此用户明确要求安装时设置 all-visible 与 keep-configured。离屏、后台、关闭视图及卸载停止。所有自动播放入口强制静音，手动播放仍可有声音并保留手动优先策略。
